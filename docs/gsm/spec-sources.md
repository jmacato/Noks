# Specification lookup points

These are the specifications that the GSM stack in `src/Noks.Dct3` implements. It uses public ETSI specifications from the GSM period. This repository holds no specification PDFs and no generated text copies of them, which keeps it small and redistributes no third-party document.

- GSM 03.22 v7.2.0, MS idle mode and cell selection:
  https://www.etsi.org/deliver/etsi_ts/100900_100999/100930/07.02.00_60/ts_100930v070200p.pdf
- GSM 04.04 v7.0.0, Layer 1 primitives:
  https://www.etsi.org/deliver/etsi_ts/100900_100999/100936/07.00.00_60/ts_100936v070000p.pdf
- GSM 04.06 v8.4.0, LAPDm:
  https://www.etsi.org/deliver/etsi_ts/100900_100999/100938/08.04.00_60/ts_100938v080400p.pdf
- GSM 04.07 v7.3.0, Layer 3 service primitives:
  https://www.etsi.org/deliver/etsi_ts/100900_100999/100939/07.03.00_60/ts_100939v070300p.pdf
- GSM 04.08 v7.1.3, RR/MM/CC messages:
  https://www.etsi.org/deliver/etsi_en/300900_300999/300940/07.01.03_60/en_300940v070103p.pdf
- GSM 04.11 v6.1.0, point-to-point SMS:
  https://www.etsi.org/deliver/etsi_ts/100900_100999/100942/06.01.00_60/ts_100942v060100p.pdf
- GSM 05.02 v7.6.1, frame/channel mapping:
  https://www.etsi.org/deliver/etsi_TS/100900_100999/100908/07.06.01_60/ts_100908v070601p.pdf
- GSM 05.08 v7.7.0, radio link and measurements:
  https://www.etsi.org/deliver/etsi_TS/100900_100999/100911/07.07.00_60/ts_100911v070700p.pdf
- GSM 11.11 v7.5.0, SIM-ME interface: locate ETSI TS 100 977 v7.5.0 in the
  ETSI deliverables archive.

GSM 04.06 specifies the LAPDm frame formats. GSM 04.08 sections 9.1 and 10.5 specify Paging, Immediate Assignment, and RR/MM/CC encoding. GSM 04.11 specifies CP/RP messaging. GSM 05.02 sections 6 and 7 specify control-channel scheduling.
