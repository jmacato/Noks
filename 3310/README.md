# Flash dumps

Noks ships no Nokia firmware. Put your own `.fls` flash dump in this directory to boot a handset. The repository ignores `*.fls`, so a dump placed here is never committed.

The CLI and the desktop app default to `3310/My 3310 NR2 v.4.18.en.fls`. To use another dump, pass its path as the first argument or with `--flash <path>`.

Read a dump from hardware you own, or get one from another source you are entitled to use. Check what your local law permits before you do.
